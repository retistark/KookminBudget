국민가계부에서 구글 로그인으로 만든 계정과, 동기화로 서버에 저장된 데이터의 삭제를 요청하는 방법을 안내합니다.

1. 계정 삭제 요청 방법

  1. 아래 이메일 주소로 메일을 보내 주세요.
  2. 제목에 [국민가계부 계정 삭제 요청]이라고 적어 주세요.
  3. 본문에 앱에서 로그인할 때 쓴 구글 계정 이메일 주소를 적어 주세요.
    (본인 확인을 위해 가능하면 그 구글 계정으로 메일을 보내 주세요.)

이메일: retiguy@gmail.com

요청을 받으면 지체 없이, 늦어도 30일 이내에 삭제하고 처리 결과를 메일로 알려드립니다.

2. 삭제되는 데이터

  • 로그인 계정 정보(구글 계정 식별자, 이메일 주소)
  • 동기화로 서버에 저장된 가계부 데이터 전체(내역, 장부, 카테고리, 자산, 고정비, 할부, 카드실적 목표, 메모 등)

3. 보관되는 데이터

  • 삭제 후 서버에 보관하는 개인정보는 없습니다.
  • 이용자가 설정에서 켠 경우 모인 익명 알림 읽기 통계(날짜, 알림 보낸 앱 이름, 건수 등)는 개인을 알아볼 수 없는 정보라 계정과 연결되지 않으며, 기능 개선 목적이 끝나면 지웁니다.

4. 계정은 두고 데이터만 지우고 싶을 때

  • 위 이메일로 [국민가계부 데이터 삭제 요청]이라고 보내 주시면 계정은 유지하고 서버의 동기화 데이터만 지워 드립니다.
  • 휴대폰에 저장된 데이터는 앱 안에서 직접 지우거나, 앱을 삭제하거나, 휴대폰 설정 > 앱 > 국민가계부 > 저장공간 > 데이터 삭제로 바로 지울 수 있습니다.
